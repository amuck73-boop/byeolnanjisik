별난지식 업로드 도구 · 시행일 2026년 11월 23일

1. 이 도구는 무엇인가요

별난지식 업로드 도구는 유튜브 채널 '별난지식' 운영자가 자기 채널에 영상을 올리고 관리하기 위해 직접 만든 프로그램입니다. 일반 사용자에게 제공하는 서비스가 아니며, 채널 운영자 본인 계정으로만 사용합니다.

2. 어떤 정보를 쓰나요

이 도구는 YouTube Data API를 통해 운영자 본인 채널의 다음 기능만 사용합니다.

  • 영상 업로드와 제목·설명·태그·썸네일·자막 설정
  • 재생목록 관리
  • 운영자 채널 영상의 댓글 읽기와 채널 이름으로 댓글·답글 달기
  • 운영자 채널의 조회수 등 성과 확인

다른 사람의 개인정보는 수집하지 않습니다. 시청자 댓글은 답글을 달고 주제 요청을 모으는 데만 쓰며, 따로 저장해 두거나 다른 곳에 넘기지 않습니다.

3. 정보는 어디에 보관되나요

구글 로그인 인증 정보(토큰)는 운영자의 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다. 제3자에게 판매하거나 제공하지 않습니다.

4. 구글 정책 준수

이 도구가 구글 API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 이 도구는 YouTube API 서비스를 사용하므로 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 권한을 거두려면

언제든지 구글 계정의 '서드파티 앱 및 서비스'에서 이 도구의 접근 권한을 삭제할 수 있습니다.

6. 문의

유튜브 별난지식 채널을 통해 문의해 주세요.
